# Календарь денег

Тестовая версия **0.1.5**. Календарь поступлений, трат и обязательных платежей с дневным лимитом на 30, 60 или 90 дней.

## Для тестировщиков

1. Откройте опубликованный сайт по ссылке из блока About репозитория.
2. Внесите доходы и расходы. При необходимости уточните фактический остаток.
3. Добавьте ближайшее поступление, обязательные платежи и обычные траты.
4. Проверьте дневной лимит, оплату, отмену покупки и досрочный частичный платёж.
5. Проверьте сайт на телефоне. В сообщении об ошибке укажите модель, браузер и версию приложения.

Новые пользователи начинают с пустого календаря. Тестовый пример можно включить переключателем.
Внизу сайта есть кнопки «Сообщить об ошибке» и «Предложить улучшение». Для отправки через GitHub нужен аккаунт. Можно также передать автору описание: действия → ожидаемый результат → фактический результат.

## Удаление ошибочной операции

Выберите день в календаре и нажмите «Удалить» у любой операции: дохода, траты, обязательного платежа, записи займа или тестового платежа. Для повторяющейся операции выберите удаление одной даты или всей серии. Перед удалением появится подтверждение. Прогноз и дневной лимит пересчитываются сразу.

Кнопка «Вернуть предыдущие данные» восстанавливает весь календарь до последнего удаления, сброса или импорта, включая отмену более поздних изменений. Хранится один предыдущий набор, доступный после обновления страницы.

Если удаляется уже оплаченная запись, удаляются и её отметки оплаты. Введённый вручную фактический остаток сохраняет своё значение; при ошибочной оплате, уже учтённой в этом остатке, нужно уточнить «Сколько сейчас есть». Отдельное удаление поступления или возврата займа сохраняет его карточку и остальные операции. Удаление платы за перенос сохраняет новый срок; отмена самого переноса доступна в карточке займа.

В блоке «Мои займы» есть кнопка «Удалить заём». Она удаляет весь заём с поступлением, погашениями и переносами. Удаление требует подтверждения; календарь до удаления можно восстановить кнопкой «Вернуть предыдущие данные». Введённый вручную остаток денег не переписывается.

Сохранение траты, дохода или платежа возвращает фокус без принудительной прокрутки страницы.

Расчётный остаток и дневной лимит работают без ручного ввода фактической суммы: из начального остатка, отмеченных поступлений и оплат. Будущие доходы входят в прогноз, а доступными становятся после отметки получения. Ручной фактический остаток — необязательное уточнение, от которого продолжается дальнейший расчёт.

## Повторяющиеся обязательные платежи

При добавлении обязательного платежа доступны повторы каждый день, каждую неделю или каждый месяц. При необходимости укажите последнюю дату. Каждый повтор имеет отдельный статус оплаты и входит в прогноз и дневной лимит. Если нужного числа нет в месяце, используется последний день; в следующем месяце сохраняется исходное число.

## Дневной лимит

По умолчанию проверяются ближайшие 30 дней, включая сегодня. В блоке лимита можно выбрать 60 или 90 дней. Подбирается одинаковая дополнительная сумма на каждый день, при которой остаток не отрицательный ни на одну дату выбранного периода. Учитываются все запланированные доходы и расходы, обязательства и резервы, включая платежи после ближайшего поступления. Если денег не хватает уже на внесённый план, показываются нулевой лимит и дата нехватки.

## Где хранятся данные

Записи хранятся в localStorage браузера. Сервера с пользовательскими данными нет. У каждого браузера отдельный календарь. Для переноса между устройствами скачайте резервную копию и восстановите её на другом устройстве.

Не добавляйте личную резервную копию в публичный репозиторий или обращение. При переходе со старого адреса сайта записи сами не перенесутся: используйте экспорт и импорт.

## Публикация GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/(root)`, затем Save. GitHub покажет адрес после публикации. Файл `.nojekyll` отключает обработку Jekyll. Сборки и внешних зависимостей нет.

## Локальный запуск

Запустите HTTP-сервер, например `python3 -m http.server 8080`, и откройте http://localhost:8080. Запуск двойным щелчком по index.html может блокировать ES-модули.

## Проверки расчётов

Нужен Node.js:

```sh
node tests/cancellation.mjs
node tests/daily-allowance.mjs
node tests/income-cycle.mjs
node tests/operations.mjs
node tests/automatic-balance.mjs
node tests/delete-any.mjs
node tests/monthly-payments.mjs
```

Проверяются отмены, резервные копии, частичные платежи, приход денег и расчёт на выбранный период.

## Ограничения тестовой версии

Автоматической синхронизации и банковских интеграций нет. Вёрстка адаптивная; полноценная проверка на реальных телефонах ещё нужна. Дневной лимит предполагает актуальные даты и суммы в календаре. Лимит проверяет каждую дату выбранного периода и учитывает все внесённые доходы и платежи внутри него. Выбор периода сохраняется в этом браузере.
